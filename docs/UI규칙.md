# 《요원》 UI·연출 규칙 (2026-11-28)

> 화면 그림은 `docs/맵구상도.drawio`. 전투 규칙은 `docs/전투규칙.md`, 성장·경제는 `docs/성장경제규칙.md`.

## 1. 휴대폰 메뉴 (오른쪽 스와이프)

- 화면 오른쪽 가장자리에서 안쪽으로 밀면 휴대폰 화면이 열린다. 휴대폰 컨셉.
- 휴대폰에서 볼 것: 내 정보(지금의 홈·스탯 창 탭들: 스탯, 장비, 인벤토리, 성장), 미션(본사 다크웹, D단계), 설정 등 여러 메뉴.
- 웹(마우스)에서도 열 수 있어야 한다: 오른쪽 가장자리 드래그 + 프로필 버튼을 눌러도 같은 휴대폰이 열린다.
- 지금의 홈 창은 휴대폰 안의 "내 정보" 앱으로 옮긴다. 기능(장착, 사용, 스탯 찍기, 전투 중 보기 전용)은 그대로.
- 빨간 점(남은 포인트·재능·특성, 새 미션)은 프로필 버튼과 휴대폰 아이콘에 표시.
- 시점: D단계 시작 때 휴대폰 틀을 만들고 미션과 함께 넣는다.

## 2. 왼쪽 스와이프

- 미정. 자리만 비워 둔다 (아무 동작 없음).

## 3. 전투 화면 연출

- 체력이 낮을 때: 화면 가장자리에 불투명도가 낮은 빨간색이 깔린다.
  - 임시: 체력 30% 이하부터 나타나고, 낮을수록 조금 진해진다. 최대로 진해도 글자·버튼을 가리지 않는 정도.
  - 회복해서 30%를 넘으면 서서히 사라진다.
- 정신 공격을 받았을 때: 화면 가장자리에 불투명도가 낮은 검은색이 깔린다.
  - 정신 계열 디버프(임시: 사기 저하. 앞으로 정신 계열로 표시한 디버프)에 걸려 있는 동안 유지, 풀리면 서서히 사라진다.
- 둘 다 과하지 않게: 화면 전체를 덮지 않고 가장자리 위주, 깜빡임·흔들림 없이 부드럽게 나타나고 사라진다.
- 둘이 겹치면 둘 다 보이되 읽기에 방해되지 않게.
- 색·세기·기준 체력은 데이터로 조정 가능하게.

## 4. 전투 화면 배치 (맵 구상도 "전투 화면")

- 위 가운데 몬스터 체력바, 오른쪽 위 프로필·설정, 가운데 괴이와 예고 말풍선.
- 행동 버튼 4개 위 가운데에 플레이어 체력/마나, 그 왼쪽에 버프·디버프.

## 5. 만화 페이지 (맵 구상도 "만화 페이지 화면")

- 한 페이지에 사선·불규칙 칸 4개 예시. 형식은 `docs/아트방향.md`.
