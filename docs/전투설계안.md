# B단계 전투 설계안 (2026-11-26 승인, 수정 4건 반영)

> 근거: `docs/전투규칙.md`(우선), `docs/맵구상도.drawio` 전투 화면 5페이지, `docs/전투시스템.md`
> 범위: 전투규칙 12번의 B단계 항목. C단계(보상·골드·병원·상점·장비·성장)는 데이터 칸만 둔다.
> ⚠ = 규칙 문서의 "확인 필요" 또는 문서에 없어서 임시로 정한 것. 맨 아래 "확인 필요 목록"에 모아 둠.

## 0. 큰 구조

```
[데이터 SO]  BattleSettings · MonsterData · StatusEffectData · SkillData · ItemData · ComicData
                 │
[전투 엔진]  BattleEngine (순수 C#, MonoBehaviour 아님, 난수 주입)
                 │  ← 같은 엔진을 게임과 시뮬레이터가 함께 사용
      ┌──────────┴───────────┐
[전투 화면]  BattleController(UI)      [시뮬레이터]  BattleSimulator (메뉴: 요원 > 전투 시뮬레이션)
                 │
[진행 상태]  GameState.player (PlayerState: 체력·기력·스탯·주사위·아이템·복귀 지점) + flags
```

- 전투 규칙 계산은 전부 BattleEngine 안에 둔다. 화면은 엔진이 돌려주는 결과(로그)를 보여 주기만 한다.
  → 1000회 시뮬레이션이 실제 게임과 같은 규칙으로 돌고, EditMode 테스트로 계산식을 검증할 수 있다.
- 씬은 지금처럼 1개. 전투 화면·만화 뷰어는 Canvas 위 전체 화면 패널.

## 1. 데이터 구조

### BattleSettings (SO, 에셋 1개) — 전투 수치 한곳

| 칸 | 임시값 | 규칙 |
|---|---|---|
| comboMultipliers (주사위 개수별) | 2개 ×2 / 3개 ×5 / 4개 ×10 / 5개 이상 ×20 | 2번 |
| critChanceBase / critMultiplier | 5% / 1.5 | 3번 |
| minDamage | 1 | 3번 |
| defenseChanceBase / defenseChanceCap | 30% / 95% | 5번 |
| touchWindowSeconds / touchIncrement | 2초 / 터치당 +1.5%p | 5번 |
| touchBonusMax / touchBonusMin, touchBonusAttackLow / High | 15% / 5%, 괴이 공격력 10 이하 → 15%, 30 이상 → 5%, 사이는 직선 | 5번 ⚠ |
| fleeChanceBase / fleeChanceMax / fleeFailDamageMultiplier | 40% / 90% / ×2 | 5번 |
| reflectRatio | 반사 피해 = 내 공격 피해 ×1.0 | 6번 ⚠ |
| tauntEffect | 도발 상태 효과 에셋 (괴이 방어력 −30%, 공격력 +30%, 3턴, 중첩 없음) | 5번 |
| defeatGoldLossRatio / reviveHpRatio | 10% / 최대 체력 30% | 9번 ⚠ |
| retryRewardRatio / battleCooldownSeconds | 0.2 / 0 (C단계·온라인용 칸만) | 1번 |
| playerBase | 체력 100, 기력 10, 공격 5, 방어 10, 치명 5%, 민첩 0, 주사위 2개×6면, 스킬 2개(다시 굴리기·주사위 고정), 음식 3개 | 10번 |
| defaultRespawnPlace | 도심 "안전 지역"(임시 병원) | 9번 |

### MonsterData (SO, 괴이 1종 = 에셋 1개)

- monsterId, monsterName, image(Sprite 비움), description, bgm/sfx(AudioClip 칸만)
- maxHp, attack, defense
- firstStrike (선공 여부, 기본 false), canFlee (보스·스토리는 false)
- actions: List<MonsterAction>
- phases: List<BossPhase> (보스만, 비어 있으면 일반 괴이)

MonsterAction (괴이 행동 1개)

| 칸 | 설명 |
|---|---|
| actionId, actionName | 예: "arm_swing", "팔 휘두르기" |
| kind | Attack(피해) / Debuff(디버프 걸기) / Reflect(반사 자세) / Buff(자기 강화) |
| damageMultiplier | 행동 배율 (팔 휘두르기 1.0, 돌진 1.5) |
| effect | StatusEffectData (Debuff·Buff일 때) |
| weight | 선택 확률 가중치 |
| condition | 없음 / 체력 n% 이하일 때만 / 같은 행동 연속 금지 |
| telegraphVague | 정보 전 예고: "괴이가 숨을 크게 들이쉰다." |
| telegraphClear | 정보 후 예고: "소리를 질러 사기를 떨어뜨리려 한다." |

- 대표 특수 행동 = kind가 Debuff 또는 Reflect인 행동. 괴이마다 1개.
- 정보 획득: GameState 플래그 `StateKeys.MonsterInfo(monsterId)` = "info:monster:{id}".
  정보가 있으면 telegraphClear + 공격력·방어력 표시, 없으면 telegraphVague + "???".
  얻는 방법(B단계): 장소 조사(Investigate) 상호작용에 `revealsMonster` 칸 추가 → 조사하면 플래그 기록.

BossPhase (보스 페이즈 1개)

- trigger: 체력 n% 이하 / 특정 행동(actionId)을 한 뒤
- comic(ComicData, 전환 만화), attackMultiplier, defenseMultiplier
- actions(비어 있지 않으면 행동 패턴 교체), telegraphOverride(예: "도망칠 준비를 한다") ⚠

### StatusEffectData (SO, 디버프·버프 공용)

- effectId, effectName, icon(비움), isDebuff, duration(턴)
- attackPercent(공격력 ±%), defenseChancePoints(방어 확률 ±%p), damagePerTurn(턴마다 피해), healPerTurn
- blockedBy: 막는 특수 행동 (귀막기 / 호흡참기 / 입막기 / 없음)

| 에셋 | 효과 (임시) | 막는 행동 |
|---|---|---|
| 사기 저하 | 공격력 -30%, 3턴 | 귀막기 |
| 중독 | 매 턴 5 피해, 3턴 | 호흡참기 |
| 기침 | 방어 확률 -20%p, 2턴 | 입막기 |
| 격앙 (보스 버프) | 괴이 공격력 +30%, 3턴 | 없음 |
| 도발 (주인공이 괴이에게) | 괴이 방어력 −30%, 공격력 +30%, 3턴, 중첩 없음(다시 걸면 남은 턴만 3으로) | — |

- 반사는 디버프가 아니라 괴이 행동(Reflect 자세)으로 처리: 그 턴에 주인공이 공격하면 피해가 주인공에게 돌아오고, "가만히 있기"면 아무 일도 없음.
- 디버프는 방어로 막지 못한다 (규칙 5번).

### SkillData (SO) — 스킬 (첫 출시 포함)

- skillId, skillName, description, icon, energyCost, kind
- 무기에서 얻는 스킬, 장착 무기 기준 최대 2개 (무기 연동은 C단계, B단계는 시작 스킬 2개를 PlayerState.skillIds에 넣음)
- 임시 스킬 2개 (전투규칙 5번):
  - 다시 굴리기 (기력 2): 이번 공격의 주사위를 한 번 다시 굴린다
  - 주사위 고정 (기력 3): 다음 공격에서 주사위 1개의 눈을 지금 값으로 고정 (조합 노리기)
- 사용 시점: 두 스킬 모두 "주사위를 굴린 뒤, 피해 확정 전"에 쓰는 스킬 → 공격 기믹 영역에 스킬 버튼으로 표시.
  특수 행동 창의 스킬 칸 2개에는 장착 스킬을 보여 주고, 굴린 뒤에 쓰는 스킬은 "공격 중 사용" 안내와 함께 비활성 ⚠
  (나중에 턴을 쓰는 스킬이 생기면 그 칸에서 바로 사용하도록 SkillData.timing 칸으로 구분)

### 기력/마나 (수정 반영)

- 체력처럼 소비 자원. 전투마다 최대치로 시작하지 않고, 쓴 만큼 전투 후에도 유지 (PlayerState.currentEnergy)
- 전투 중 자동 회복 없음. 회복은 병원(체력·기력 따로 비용, C단계)과 아이템(ItemData.healEnergy)
- ⚠ 전투규칙.md 5번의 "전투 시작 시 최대치, 매 턴 +1 회복(임시)" 문장과 다름 → 사용자 지시(11/26)를 따름. 규칙 문서 갱신 필요

### ItemData (SO, C단계 확장 전제 최소형)

- itemId, itemName, icon, type(소비/무기/방어구/특수), healHp·healEnergy(소비), attack/defense 보너스 칸(C)
- B단계는 임시 소비 아이템 "[음식]"(체력 30 회복) 1종만 사용. 음식먹기 = 소비 아이템 1개 사용.

### ComicData (SO) — 만화 뷰어

- comicId, pages: List<Sprite>(비움), bgm(칸만)
- 페이지 이미지가 비어 있으면 회색 + "[만화 n/m 미정]" 표시

### 장소·구역 데이터에 추가하는 칸

- AreaData.encounters: List<{monster, weight}> — 일반 전투 조우 목록
- PlaceData.battle: { mode: 없음 / 일반(구역 조우 목록) / 스토리(고정 괴이), fixedMonster, introComic, allowFlee }
  - mode는 placeType(Danger)과 따로 둔다. 지금 도심 "위험 지역"은 점원 대화가 있는 장소라 mode = 없음 유지 ⚠
- PlaceInteraction.revealsMonster (괴이 정보 플래그)

## 2. 전투 흐름

```
구역 맵에서 진입하기
  ├ battle.mode 없음 → 지금처럼 장소 내부
  ├ 일반 → 구역 조우 목록에서 가중치 랜덤 → 바로 전투
  └ 스토리 → introComic 만화 뷰어 → 고정 괴이와 전투
전투 시작: firstStrike 괴이면 괴이가 먼저 1회 행동
턴 반복:
  1. 턴 시작: 괴이가 이번 턴 행동을 고르고 예고 표시 (Reflect면 바로 반사 자세)
  2. 주인공 행동: 공격 / 방어(연속 터치) / 특수 행동 / 도망
  3. 괴이 행동 실행 (괴이가 살아 있으면)
     - Attack: 방어 성공이면 0, 실패면 피해 (도망 실패 턴이면 ×2, 도발 중이면 괴이 공격력 +30%)
     - Debuff: 맞는 특수 행동을 이번 턴에 썼으면 막힘, 아니면 걸림
  4. 판정: 괴이 체력 0 → 승리 / 주인공 체력 0 → 패배 / 보스 페이즈 조건 → 전환 만화 → 페이즈 적용
  5. 턴 끝: 상태 효과 지속시간 -1, 중독 피해
승리 → 들어갔던 구역 맵 (스토리·보스면 첫 클리어 플래그 기록, 보상은 C단계)
도망 성공 → 구역 맵
패배 → 골드 10% 손실(골드는 C단계라 지금 0) → 복귀 지점 장소 내부에서 체력 30%로 시작 ⚠
```

- 체력은 전투가 끝나도 그대로 유지 (규칙 9번). 회복 수단(B단계): 음식, 임시 스킬, 패배 후 부활.

## 3. 주인공 수치 저장 (GameState, E단계 JSON 호환)

```csharp
[Serializable] public class GameState {
    public List<string> flags;            // 기존
    public PlayerState player = new PlayerState();   // 추가
}
[Serializable] public class PlayerState {
    public bool initialized;              // false면 BattleSettings.playerBase로 채움 (새 게임)
    public int currentHp, maxHp, currentEnergy, maxEnergy;
    public int attack, defense, agility; public float critChance;
    public int diceCount, diceFaces;      // C단계 성장
    public int gold;                      // C단계
    public string respawnPlaceId;         // 마지막 병원 (비면 defaultRespawnPlace)
    public string weaponId, armorId;      // C단계 장비
    public List<string> skillIds;         // 스킬 칸 2개
    public List<ItemStack> items;         // {itemId, count}
}
```

- JsonUtility가 그대로 저장할 수 있는 형태만 사용 (int, float, string, List). Dictionary 안 씀.
- 장비 보너스는 저장하지 않고 계산 시 ItemData에서 더한다 (C단계).
- 새 플래그 키 (StateKeys에 추가): MonsterInfo(monsterId), BattleCleared(locationId)

## 4. 만화 뷰어

- ComicViewer 패널(전체 화면, 맨 앞): 이미지 1장 + 페이지 표시 "1/3" + 화면 클릭 = 다음 + "건너뛰기" 버튼
- Play(ComicData, 끝나면 호출할 함수). ComicData가 없거나 페이지 0장이면 바로 끝남 처리
- 사용처: 스토리 전투 진입 전, 보스 페이즈 전환

## 5. 화면 (맵구상도 5페이지 + 규칙 11번, 1920x1080)

| 위치 | 요소 |
|---|---|
| 위쪽 가운데 | 괴이 체력바 + 숫자 |
| 오른쪽 위 | 프로필·설정 버튼 (자리만, C단계 홈·스탯 창) |
| 가운데 | 괴이 이미지(회색 사각형) + 이름 |
| 괴이 옆 | 말풍선: 예고 텍스트 |
| 아래쪽 가운데, 행동 버튼 줄 바로 위 | 주인공 체력·기력 바 (규칙 11번) |
| 그 왼쪽 | 주인공에게 걸린 버프·디버프 (이름·남은 턴). 오른쪽은 비움 |
| 공격 기믹 영역 | 주사위 결과와 예상 피해, 스킬 버튼 |
| 아래쪽 | 행동 버튼 4개: 공격 / 방어 / 특수 행동 / 도망 |

- 공격: 아래 버튼 자리가 "주사위 영역"으로 바뀜 → 주사위 2개(굴리는 동안 숫자가 바뀌는 연출) + 굴리기 버튼 → 결과·조합 배수·피해
- 방어: "방어 확률 ~% (연속 터치로 확률을 높이세요!)" 창, 2초 동안 마우스 클릭·터치마다 확률 상승, 시간이 끝나면 판정
- 특수 행동: 목록형 팝업, 한 페이지 2×2 = 4칸, X 닫기, ▶ 다음 페이지
  - 1쪽: 스킬1, 스킬2, 가만히 있기, 도발하기 (그림 그대로) / 2쪽: 귀막기, 호흡참기, 입막기, 음식먹기(개수 표시)
  - 칸 목록은 데이터 순서대로 만들어 페이지가 자동으로 나뉜다 (나중에 행동이 늘어도 코드 수정 없음)
- 도망: "도망칠 수 있는 확률 ~% / 실패 시 받는 피해 2배" 창 + 도망치기·취소. 도망 불가 전투는 버튼 비활성
- 결과 창: 승리 / 패배 / 도망 성공 + 확인

## 6. 특수 행동·도발·스킬 상세

| 행동 | 효과 | 맞지 않는 상황 |
|---|---|---|
| 가만히 있기 | 반사 자세 턴에 공격 대신 기다림 → 반사 피해 없음 | 턴 낭비 |
| 귀막기 / 호흡참기 / 입막기 | 이번 턴 괴이의 해당 계열 디버프를 막음 | 턴 낭비 |
| 음식먹기 | 소비 아이템 1개로 회복 (없으면 비활성) | — |
| 도발하기 | 괴이에게 도발 상태 효과: 방어력 −30%, 공격력 +30%, 3턴, 중첩 없음 (그 턴 괴이 공격부터 강해짐) | — |
| 스킬 1·2 | 장착 스킬 표시. 다시 굴리기·주사위 고정은 공격 기믹 영역에서 사용 ⚠ | 기력 부족 시 비활성 |

- 특수 행동은 기력을 쓰지 않는다 (스킬만 기력 사용). 특수 행동은 턴을 쓴다.

## 7. 임시 괴이 (이름·이미지 "[미정]", 수치는 시뮬레이션으로 조정)

| 구역 | 괴이 | 일반 공격 | 대표 특수 행동 | 대응 |
|---|---|---|---|---|
| 도심 | urban_1 | 팔 휘두르기 1.0 | 소리 지르기 → 사기 저하 | 귀막기 |
| 도심 | urban_2 | 팔 휘두르기 1.0, 돌진 1.5 | 몸 웅크리기 → 반사 | 가만히 있기 |

## 8. 밸런스 시뮬레이션

- 메뉴 "요원 > 전투 시뮬레이션": 괴이별 1000회, 같은 BattleEngine으로 자동 전투
- 자동 플레이 방식 2가지를 비교 보고
  - 기본형: 예고를 읽고 맞는 특수 행동, 나머지 턴은 공격, 체력 30% 이하면 방어 (연속 터치 보너스는 최대치의 절반으로 가정)
  - 단순형: 무조건 공격 (조합에만 기대는 플레이가 이기지 못하는지 확인)
- 보고 항목: 평균 턴 수(목표: 일반 3~5, 보스 12~20), 승률, 전투당 평균 피해, 조합 발동률·조합 피해 비중
- 연속 버티기: 회복 없이(음식 X) 체력·기력이 이어지는 상태로 구역 조우를 연달아 — 스킬 안 씀 / 스킬 씀 두 가지로 몇 전투 버티는지, 기력이 몇 번째 전투에서 바닥나는지 (목표 2~3회)
- 보스는 "시작 장비"와 "적정 장비 가정(공격 +5, 방어 +10)" 두 가지로
- 결과는 Console + `docs/밸런스기록.md`에 표로 남김. 목표에서 벗어나면 BattleSettings·MonsterData 수치를 고쳐 다시 돌림

## 확인 필요 목록

결정됨 (11/26 사용자): 도발 = 괴이 상태 효과(방어 −30%, 공격 +30%, 3턴, 중첩 없음) / 스킬 첫 출시 포함, 임시 스킬 = 다시 굴리기(기력 2)·주사위 고정(기력 3) / 기력은 소비 자원(전투 후 유지, 자동 회복 없음) / 아래 임시 처리 항목들은 설계안대로 진행

임시 처리 (설계안대로 진행, 밸런스·플레이 검토 때 다시 볼 것):

1. 방어 연속 터치 보너스: 강한 괴이일수록 작게(+5%), 약하면 크게(+15%)
2. 패배 후: 복귀 장소에서 최대 체력 30%로 부활 (기력은 그대로)
3. 반사 피해: 내가 준 피해 ×1.0을 내가 받음
4. 보스 3페이즈 "도망칠 준비": 예고 텍스트만
5. 도심 "위험 지역"(점원 대화 장소)은 전투 장소로 바꾸지 않음. 도심 일반 전투는 새 임시 장소에서
6. 중독 피해 시점: 턴 끝에 적용
7. 선공 괴이의 첫 행동은 예고 없이 바로 실행
8. 스킬 사용 위치: 다시 굴리기·주사위 고정은 공격 기믹 영역(굴린 뒤)에서. 특수 행동 창 스킬 칸은 표시용(비활성 + 안내)
9. 사기 저하 "공격력 −30%"는 주인공 공격 피해 전체에 적용 (공격 스탯 5만 깎으면 효과가 거의 없어서)
10. 상태 효과 지속: 괴이가 건 효과는 다음 턴부터 n턴, 도발은 건 턴 포함 n턴
11. 전투규칙.md 5번 기력 문장(전투 시작 최대치·매 턴 +1)과 사용자 지시가 다름 → 지시를 따름, 규칙 문서 갱신 필요
