## 현재 구현된 기능

1. 지도 위 네 개의 장소 (일반·안전·위험·특별), 장소별 색상 구분
2. 장소 클릭 시 파란색 선택 표시, 이전 장소 색상 복구
3. 선택한 장소로 카메라 이동·확대, 장소 옆에 정보창 표시 (이름, 유형, 설명, 진입하기, X)
4. X 버튼으로 정보창 닫기 및 카메라 초기 위치 복귀
5. 장소 내부 화면 진입 및 나가기
6. 장소 내부 버튼: 진열대 조사 / 점원과 대화 / 수상한 사람 조사
7. 조사 결과는 장소별 LocationData 문구로 결과 텍스트에 출력
8. 점원과 대화 시 대화창 (NPC 이름, 대사, 선택지 A/B, 닫기)
9. 선택지를 고르면 대화창이 닫히고 결과 텍스트에 장소별 결과 출력
10. 대화창이 열린 동안 조사 버튼 클릭 차단
11. 새 장소 진입 시 이전 결과·선택지·대화창 초기화 (상태는 유지)
12. 장소별로 선택지를 골랐는지 기억 → 재대화 시 재방문 대사만 표시 (닫기만 누르면 기억하지 않음)
13. 상태는 Play 중에만 유지 (저장은 E단계)

## 현재 스크립트

### LocationData.cs (각 장소 오브젝트에 부착)

- 장소 정보: locationName, locationType(Normal/Safe/Danger/Special), description
- 상호작용 결과: shelfResult, clerkResult(점원 첫 대사), suspiciousPersonResult
- 점원 대화: npcName, choiceAText, choiceAResult, choiceBText, choiceBResult, clerkRepeatDialogue
- 상태: hasChosenClerkChoice ([System.NonSerialized])

### LocationSelector.cs (Locations 오브젝트에 부착)

- 마우스 클릭으로 장소 선택, 색상 표시/복구
- 카메라 이동·확대, 정보창 위치 계산 UpdatePanelPosition (캔버스 크기 기준 계산이라 가로에서도 코드 변경 없음. 세로 시절 "폭 490 미만" 제한은 가로에서 해소)
- zoomedCameraOffsetX (A단계 추가): 확대 시 카메라를 장소 기준 오른쪽으로 옮겨 장소를 화면 왼쪽에 둠. 기본 0
- 인코딩: UTF-8 변환 완료 (A단계 1번 작업 중)
- EnterSelectedLocation(): 장소 진입, InteractionController.SetLocationData()로 데이터 전달
- ExitPlace(): 지도 복귀
- CloseLocationInfo(): 정보창 닫기, 카메라 초기화

### InteractionController.cs (PlaceInteriorPanel에 부착)

- SetLocationData(): 현재 장소 데이터 저장, 결과·선택지·대화창 초기화 (상태는 유지)
- InvestigateShelf() / TalkToClerk() / InvestigateSuspiciousPerson(): 버튼 OnClick 연결 (이름 변경 금지)
- TalkToClerk(): 이미 선택했으면 재방문 대사, 아니면 첫 대사 + 선택지
- ChooseA() / ChooseB(): 상태 기록 후 대화창 닫고 결과 표시
- CloseDialogue(): 대화창 닫기
- 내부: OpenDialogue(string), ShowChoices, HideChoices, DisplayResult

## UI 구조 (PlaceInteriorPanel, 가로 1920x1080 기준 배치)

- PlaceNameText (상단 중앙), ExitButton (좌상단)
- PlaceDescriptionText (위쪽), InteractionResultText (화면 중앙)
- InteractionArea (조사 버튼 3개, 아래쪽 y -310) — 대화창이 열리면 대화창에 완전히 가려져 클릭 차단
- DialoguePanel (하단 띠 1600x420, y -310, 불투명 배경. 계층 맨 아래여야 위에 그려짐, 처음엔 꺼짐)
  - 왼쪽 CharacterImage(회색 자리) / 가운데 NpcNameText·DialogueText / 오른쪽 위 CloseDialogueButton
  - ChoicePanel (오른쪽, 처음엔 꺼짐): ChoiceAButton, ChoiceBButton (글자 자동 크기 20~30)
- 지도 정보창 LocationInfoPanel 480x800: 위치는 코드(UpdatePanelPosition)가 계산, panelOffset 160으로 확대된 장소와 겹치지 않음

## 결정 사항

- 개발 방식 (11/26): 바이브 코딩. Claude Code = 코드·씬·Inspector·테스트 (Unity MCP), 사용자 = 최종 검토·커밋
- 장소 내부 나가기 버튼은 좌상단, 대화 중에도 누를 수 있음 (다시 들어오면 대화창 초기화됨) (A-1)
- 스토리·그래픽 (11/26): 비워 둠. 텍스트·이미지는 ScriptableObject 칸으로 교체 가능하게
- 첫 출시 (11/26): itch.io 웹(WebGL)
- 첫 출시 분량 (11/26): 지역 1개(구역 1~2개 + 산 + 강), 스토리 장소 고정, 서식지별 괴이 랜덤, 괴이 10종 이하, 보스 1종
- 화면 방향: 세로(Day 8) → 11/26 가로 전용으로 변경. 세로 미지원
- 대화창이 열리면 조사 버튼은 가려서 누를 수 없음 (Day 9)
- 선택지를 고르면 대화창을 바로 닫고 결과는 결과 텍스트에 표시 (Day 9)
- 재방문 대사는 장소마다 하나 (Day 10)
- 폰트 SDF(NotoSansKR-Regular SDF.asset)는 실행 중 자동 변경되므로 매번 커밋하지 않음

## 기획 메모

- 안전 지역(편의점·병원): 재화 사용, 회복, 아이템 구매 + 대화
- 특수 지역: 선택지 이벤트 후 전투 (선택 기억 필요)
- 일반 전투 지역: 진입 즉시 전투 → B단계에서 EnterSelectedLocation()에 LocationType별 분기
- 진행 유지는 E단계 세이브/로드, 기기 간 동기화는 출시 후 온라인 기능에서 검토
- 산·강: 서식지별 괴이 랜덤 등장 장소

## 나중에 처리할 문제

1. 장소 내부 화면 뒤로 지도가 비침 (내부 배경 없음) → A단계
2. 장소 유형이 영어(Safe 등)로 표시 → 한글 표시 → A단계
3. 한글 폰트 용량(SDF 약 18MB, 미사용 SDF 2개 포함), "inconsistent result" 경고 → E단계 (웹 출시라 중요)
4. 장소 내부 버튼이 모든 장소에서 동일 → 유형별 구성 → D단계
5. 일부 스크립트가 CP949로 저장됨 → A단계에서 UTF-8 통일 (LocationSelector.cs 완료, LocationData.cs·InteractionController.cs 남음)
6. 상태(hasChosenClerkChoice)가 장소 데이터와 섞여 있음 → 데이터·상태 분리 → A단계
7. ~~가로 전환~~ → A-1에서 완료
8. 진입하기 버튼(EnterButton)에 배경 이미지가 없어 글자만 보임 → 내부 배경 작업 때 같이
9. 지도 클릭은 MCP 테스트에서 코드로 대신 호출함(SelectLocation). 실제 마우스 클릭은 사용자 검토에서 확인
