## 현재 구현된 기능

1. 게임 시작 = 지역 맵 (구역 마커 3개: 도심·산·강). 지도 이미지가 없으면 회색 배경 (16x9 영역)
2. 지역 맵·구역 맵 공통: 마커 클릭 → 카메라 확대 + 정보창(이름, 유형, 설명, 진입하기, X) → 진입하기
3. 구역 마커 진입 → 구역 맵 (도심: 장소 4곳, 산·강: 임시 Danger 장소 각 2곳). 마커 색은 장소 유형별
4. 선택 표시: 마커에 어두운 테두리 + 1.15배 확대 (색은 바꾸지 않음), 이전 선택 해제
5. X 버튼으로 정보창 닫기 및 카메라 초기 위치 복귀
5-1. 구역 맵 좌상단 "지역 지도로" 버튼 → 지역 맵 (정보창 닫고 카메라 즉시 초기화). 지역 맵에서는 숨김
5-2. 장소 내부 화면 진입 및 나가기 (나가기 → 구역 맵, 정보창 열린 상태)
6. 장소 내부 버튼은 장소 데이터의 상호작용 목록대로 자동 생성 (현재 4곳 모두: 진열대 조사 / 점원과 대화 / 수상한 사람 조사)
7. 조사(Investigate): 데이터의 결과 문구를 결과 텍스트에 출력
8. 대화(Talk): 대화창 (NPC 이름·이미지 자리, 대사, 선택지 최대 2개, 닫기). 선택지가 1개면 B 버튼 숨김
9. 선택지를 고르면 대화창이 닫히고 결과 텍스트에 결과 출력
10. 대화창이 열린 동안 조사 버튼 클릭 차단
11. 새 장소 진입 시 이전 결과·선택지·대화창 초기화, 버튼 다시 생성 (상태는 유지)
12. 대화별로 선택 여부와 고른 선택지를 기억 → 재대화 시 재방문 대사만 표시 (닫기만 누르면 기억하지 않음)
13. 진행 상태는 GameStateManager 한곳에서 관리. Play 중에만 유지 (JSON 변환 함수는 준비됨, 파일 저장은 E단계)
14. NPC 이미지·내부 배경 이미지 칸: 데이터에 이미지를 넣으면 표시, 비어 있으면 회색 유지
15. 새 장소는 PlaceData 에셋을 만들고 AreaData의 places 목록에 한 줄(장소 + 비율 좌표) 추가하면 동작. 새 구역도 AreaData 에셋 + RegionData의 areas 목록 한 줄 (씬·코드 수정 불필요)
16. 지도 상태(어느 구역에 있는지)는 저장하지 않음 → E단계에서 GameState에 추가

## 현재 스크립트

모든 스크립트 UTF-8

### PlaceData.cs (ScriptableObject, 장소 1곳 = 에셋 1개) — 메뉴: Create > 요원 > 장소 데이터

- locationId (상태 키용 고유 ID, 출시 후 변경 금지), placeName, placeType(Normal/Safe/Danger/Special), description, interiorBackground(Sprite)
- interactions: List<PlaceInteraction> (순서 = 버튼 순서)
  - PlaceInteraction: interactionId(장소 안에서 고유), label(버튼 글자), type(Investigate/Talk), resultText, talk(TalkData)
  - TalkData: npc(NpcData), firstLine, choices(List<TalkChoice>: text, result), repeatLine
- OnValidate: ID가 비었거나 ':' 포함, interactionId 중복 시 Inspector에서 경고
- 같은 파일에 InteractionType, PlaceInteraction, TalkData, TalkChoice 정의

### NpcData.cs (ScriptableObject, 인물 1명 = 에셋 1개) — 메뉴: Create > 요원 > NPC 데이터

- npcId, npcName, portrait(Sprite). 여러 장소에서 재사용 (현재 Npc_Clerk 하나를 4곳이 공유)

### StateKeys.cs (static, 상태 키는 여기서만 만든다)

- TalkChosen(locationId, interactionId) → "talk:normal:clerk" (선택지를 골랐음)
- TalkChoice(locationId, interactionId, index) → "talk:normal:clerk:choice=0" (0 = A, 1 = B)
- IsValidId(id): 비어 있지 않고 ':' 없음

### RegionData.cs (ScriptableObject, 지역 1개) — 메뉴: Create > 요원 > 지역 데이터

- regionId, regionName, description, mapImage(Sprite, 비움)
- areas: List<AreaEntry> (area: AreaData, mapPosition: 비율 좌표 0~1)

### AreaData.cs (ScriptableObject, 구역 1개) — 메뉴: Create > 요원 > 구역 데이터

- areaId, areaName, areaType(Urban/Mountain/River — B단계 서식지 기준), description, mapImage(Sprite, 비움)
- places: List<PlaceEntry> (place: PlaceData, mapPosition: 비율 좌표 0~1)

### MapView.cs (씬의 MapView 오브젝트에 부착, 위치 (0,0) = 지도 중앙)

- startRegion(시작 지역), mapSize(16x9 월드 단위), background(MapBackground), emptyMapSprite(Square), markerPrefab(MapMarker)
- 색 칸: emptyMapColor, normalColor(회청), safeColor(초록), dangerColor(빨강), specialColor(노랑), areaColor(흰회색)
- ShowRegion(region) / ShowArea(area): 배경과 마커를 데이터대로 다시 그림. CurrentRegion, CurrentArea(null = 지역 맵)
- ToWorld(비율 좌표) → 월드 좌표, ColorFor(장소 유형)

### MapMarker.cs (MapMarker 프리팹, 실행 중 생성)

- Place 또는 Area 중 하나를 가리킴. DisplayName / TypeText / Description
- SetSelected(bool): selectionOutline(자식, 어두운 테두리) 켜기 + selectedScale(1.15) 확대
- 프리팹 구성: SpriteRenderer(Square) + BoxCollider2D(1x1) + MapMarker, 자식 SelectionOutline(1.3배, 꺼짐)

### GameState.cs (일반 클래스, 씬에 붙이지 않음)

- 진행 상태 묶음: List<string> flags. JsonUtility로 그대로 저장 가능

### GameStateManager.cs (씬의 GameState 오브젝트에 부착, 하나만 존재)

- GameStateManager.Instance 로 접근 (Inspector 연결 불필요. 씬에 없으면 경고 후 임시 생성)
- HasFlag / SetFlag (키는 StateKeys로 생성). 점원 전용 함수는 A-3에서 제거
- ToJson / LoadFromJson: E단계 세이브/로드용
- Play 중 Inspector에서 State.flags 확인 가능

### LocationSelector.cs (Locations 오브젝트에 부착)

- 마우스 클릭으로 MapMarker 선택 (SelectMarker, 테두리 표시), 카메라 이동·확대, 정보창 위치 계산 UpdatePanelPosition
- zoomedCameraOffsetX(1), panelOffset(200: 선택된 마커 반폭 161px + 여유)
- Inspector 칸 추가 (A-4): mapView, backToRegionButton
- EnterSelectedLocation(): 구역 마커면 구역 맵으로(EnterArea), 장소 마커면 장소 내부 (OnClick, 이름 유지)
- ExitPlace(): 장소 내부 → 구역 맵 (OnClick)
- CloseLocationInfo(): 정보창 닫기, 카메라 초기화 (OnClick)
- BackToRegion(): 구역 맵 → 지역 맵 (BackToRegionButton OnClick, A-4 추가)
- 맵 전환 시 카메라는 즉시 초기 위치·크기로

### InteractionController.cs (PlaceInteriorPanel에 부착)

- SetPlaceData(PlaceData): 결과·대화창 초기화, 배경 적용, 상호작용 버튼을 템플릿에서 다시 생성 (상태는 유지)
- ChooseA() / ChooseB() / CloseDialogue(): 버튼 OnClick 연결 (이름 변경 금지). ChooseA = 선택지 0번, ChooseB = 1번
- 내부: OnInteraction(종류별 분기), StartTalk, Choose(index), OpenDialogue(npc, 대사), ShowChoices(최대 2개), HideChoices, DisplayResult
- Inspector 칸: interactionResultText, choicePanel, choiceAButtonText, choiceBButtonText, dialoguePanel, npcNameText, dialogueText, interactionButtonTemplate, characterImage, interiorBackgroundImage
- ID가 비어 있으면 대체값(에셋 이름 / "i순번") + 경고

## 결정 사항

- 개발 방식 (11/26): 바이브 코딩. Claude Code = 코드·씬·Inspector·테스트 (Unity MCP), 사용자 = 최종 검토·커밋
- 장소 내부 나가기 버튼은 좌상단, 대화 중에도 누를 수 있음 (다시 들어오면 대화창 초기화됨) (A-1)
- 데이터·상태 분리 (A-2): 데이터(PlaceData·NpcData 에셋)는 읽기 전용, 진행 상태는 GameStateManager 한곳. 상태 키는 이름이 아닌 ID (이름은 교체 가능, ID는 출시 후 변경 금지)
- 상태 키 (A-3): StateKeys에서만 생성. 형식 "종류:장소ID:상호작용ID[:추가정보]", ID에 ':' 금지. 대화 1개마다 선택 여부 + 고른 선택지 번호 기록 (장소당 대화 개수 제한 없음). 기존 "clerkChoice:" 키는 폐기 (세이브 파일 없어서 호환 불필요)
- 장소 내부 구성 (A-3): 고정 버튼 3개 대신 상호작용 목록. 종류는 Investigate/Talk, D단계에서 Shop 등 추가. 나가기는 고정 버튼 유지
- 이름 규칙 (A-3): 지역 = Region, 구역 = Area, 장소 = Place. 장소 데이터 = PlaceData, 지도 위 오브젝트 = LocationMarker
- 선택지 UI는 버튼 2개 고정 (데이터는 목록, 3개 이상이면 경고) (A-3)
- 맵 구조 (A-4): 전체 맵(가상 한국) 없음, 게임은 지역 맵에서 시작. 지역 맵도 구역 맵과 같은 방식(클릭 → 확대 → 정보창 → 들어가기)
- 마커 위치 (A-4): 씬 오브젝트가 아닌 데이터(RegionData·AreaData)의 비율 좌표 0~1. 지도 이미지를 바꿔도 위치 비율 유지. 숫자 입력이 불편하면 지도 이미지 생긴 뒤 미리보기 도구 검토
- 선택 표시 (A-4): 색 덧칠 대신 어두운 테두리 + 확대 (흰 테두리는 흰회색 구역 마커와 구분이 안 돼 어둡게). 유형 색은 MapView 칸 한곳에서 관리
- 스토리·그래픽 (11/26): 비워 둠. 텍스트·이미지는 ScriptableObject 칸으로 교체 가능하게
- 첫 출시 (11/26): itch.io 웹(WebGL)
- 첫 출시 분량 (11/26): 지역 1개(구역 1~2개 + 산 + 강), 스토리 장소 고정, 서식지별 괴이 랜덤, 괴이 10종 이하, 보스 1종
- 화면 방향: 세로(Day 8) → 11/26 가로 전용으로 변경. 세로 미지원
- 대화창이 열리면 조사 버튼은 가려서 누를 수 없음 (Day 9)

## 기획 메모

- 안전 지역(편의점·병원): 재화 사용, 회복, 아이템 구매 + 대화 → D단계에서 상호작용 종류 Shop 추가

- 서식지별 랜덤 조우 → B단계에서 AreaData.areaType(Mountain/River)을 서식지로 쓰고, 조우 목록 칸을 AreaData 또는 PlaceData에 추가 (SO에 칸 추가는 기존 에셋을 깨지 않음)
- 산·강 임시 장소(Place_Mountain_1·2, Place_River_1·2)는 Danger 유형, 조사 버튼 1개, 문구 "[미정]" → B단계 전투 분기 시험 대상
- 진행 유지는 E단계 세이브/로드, 기기 간 동기화는 출시 후 온라인 기능에서 검토

## 나중에 처리할 문제

1. 장소 내부 화면 뒤로 지도·"지역 지도로" 버튼이 비침 (내부 배경 반투명, 클릭은 막힘) → A단계 5번 (배경 이미지 칸은 A-3에서 준비됨)

3. 한글 폰트 용량(SDF 약 18MB, 미사용 SDF 2개 포함), "inconsistent result" 경고 → E단계 (웹 출시라 중요)
4. ~~장소 내부 버튼이 모든 장소에서 동일~~ → A-3에서 데이터 목록으로 해결 (유형별 실제 구성은 D단계)
5. 진입하기 버튼(EnterButton)에 배경 이미지가 없어 글자만 보임 → 내부 배경 작업 때 같이
6. 지도 클릭은 MCP 테스트에서 코드로 대신 호출함(SelectLocation). 실제 마우스 클릭은 사용자 검토에서 확인
7. ~~선택 표시색이 장소 색과 겹침~~ → A-4에서 테두리 방식으로 해결 (정정: 겹치던 곳은 안전 지역이 아니라 일반 지역(0.11,0.27,0.91)이었음. A-3 보고는 Play 중 선택 상태 값을 읽은 오류)
8. 상호작용 버튼 5개 이상이면 InteractionArea(1400) 밖으로 넘침 → D단계 유형별 구성 때 줄바꿈 또는 크기 조정 (4개까지 확인)
9. 정보창 유형 글자가 영어(Urban, Danger 등) → A단계 5번 한글 표시 때 구역 유형도 같이
10. 진입하기 버튼 글자는 구역·장소 모두 "진입하기" → 필요하면 구역은 "들어가기"로 (A-5 때 검토)

## 출시 전 재결정

- Run In Background (A-4에서 켬): 웹 빌드에서 브라우저 탭이 비활성일 때도 게임이 계속 돎. 턴제라 큰 문제는 없지만 사운드(E단계)가 들어가면 끄는 쪽 검토. 끄면 MCP 테스트 때만 실행 중 Application.runInBackground = true 사용

## MCP 테스트 메모 (Claude Code용)

- Unity 에디터가 활성 창이 아니면 Play 중 프레임이 멈춤 → A-4에서 Player Settings Run In Background를 켜서 해결 (끄게 되면 테스트 시작 시 Application.runInBackground = true)
- 마커는 Marker_{id} 이름으로 MapView 아래에 생성됨 (선택 테스트: SelectMarker를 리플렉션으로 호출)
- 데이터 추가 테스트는 에셋을 건드리지 않게 Instantiate(region)으로 메모리 복제본에 추가해서 확인
- EditorApplication.QueuePlayerLoopUpdate()는 쓰지 말 것 (PlayerLoop 재귀 오류가 Console에 남음)
- refresh_unity 직후 Play 모드가 켜져 있는 경우가 있음 → 씬 작업 전 isPlaying 확인
- 스크린샷은 Temp/ 대신 스크래치 폴더로 옮김
