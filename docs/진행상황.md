## 현재 구현된 기능

1. 게임 시작 = 지역 맵 (구역 마커 3개: 도심·산·강). 지도 이미지가 없으면 회색 배경 (16x9 영역)
2. 지역 맵·구역 맵 공통: 마커 클릭 → 카메라 확대 + 정보창(이름, 한글 유형 "장소 유형: 위험"/"구역 유형: 산", 설명, 진입하기, X) → 진입하기
3. 구역 마커 진입 → 구역 맵 (도심: 장소 4곳, 산·강: 임시 Danger 장소 각 2곳). 마커 색은 장소 유형별
4. 선택 표시: 마커에 어두운 테두리 + 1.15배 확대 (색은 바꾸지 않음), 이전 선택 해제
5. X 버튼으로 정보창 닫기 및 카메라 초기 위치 복귀
5-1. 구역 맵 좌상단 "지역 지도로" 버튼 → 지역 맵 (정보창 닫고 카메라 즉시 초기화). 지역 맵에서는 숨김
5-2. 장소 내부 화면 진입 및 나가기 (나가기 → 구역 맵, 정보창 열린 상태)
6. 장소 내부 버튼은 장소 데이터의 상호작용 목록대로 자동 생성 (현재 4곳 모두: 진열대 조사 / 점원과 대화 / 수상한 사람 조사)
7. 조사(Investigate): 데이터의 결과 문구를 결과 텍스트에 출력
8. 대화(Talk): 대화창 (NPC 이름·이미지 자리, 대사, 선택지 최대 2개, 닫기). 선택지가 1개면 B 버튼 숨김
9. 선택지를 고르면 대화창이 닫히고 결과 텍스트에 결과 출력
10. 대화창이 열린 동안 조사 버튼 클릭 차단
11. 새 장소 진입 시 이전 결과·선택지·대화창 초기화, 버튼 다시 생성 (상태는 유지)
12. 대화별로 선택 여부와 고른 선택지를 기억 → 재대화 시 재방문 대사만 표시 (닫기만 누르면 기억하지 않음)
13. 진행 상태는 GameStateManager 한곳에서 관리. Play 중에만 유지 (JSON 변환 함수는 준비됨, 파일 저장은 E단계)
14. NPC 이미지·내부 배경 이미지 칸: 데이터에 이미지를 넣으면 표시, 비어 있으면 회색 유지. 내부 배경은 불투명이라 뒤의 지도·버튼이 비치지 않음 (A-5)
15. 새 장소는 PlaceData 에셋을 만들고 AreaData의 places 목록에 한 줄(장소 + 비율 좌표) 추가하면 동작. 새 구역도 AreaData 에셋 + RegionData의 areas 목록 한 줄 (씬·코드 수정 불필요)
16. 지도 상태(어느 구역에 있는지)는 저장하지 않음 → E단계에서 GameState에 추가
17. [B-1, 화면 없음] 전투 규칙 엔진: 주사위·조합 배수·치명타·피해식·최소 피해, 방어(연속 터치 보너스·상한 95%), 도망(실패 시 피해 2배, 보스·스토리 불가), 특수 행동(가만히 있기·귀막기·호흡참기·입막기·음식먹기·도발), 스킬 2개(다시 굴리기·주사위 고정, 기력 소비·자동 회복 없음), 디버프·버프(중첩 없음), 반사 자세, 괴이 행동 선택(가중치·조건)·예고(정보 전/후), 보스 페이즈 전환, 선공
18. [B-1] 괴이 정보: 도심 "위험 지역"의 수상한 사람 조사 → urban_1 정보 플래그 기록 (전투 화면에서 정확한 예고로 쓰임, B-3)
19. [B-1] 전투 장소 데이터: 산·강 임시 장소 4곳 = 일반 전투, 도심 뒷골목(새) = 일반 전투, 산 정상(새) = 스토리(보스)
20. [B-2] 전투 장소 진입 → 바로 전투 화면 (일반: 구역 조우 목록 가중치 랜덤 / 스토리: 고정 괴이, 만화는 B-4). 전투 아닌 장소는 지금처럼 내부
21. [B-2] 전투 화면: 위쪽 괴이 체력바, 오른쪽 위 프로필·설정(자리만), 가운데 괴이(회색)·이름·공격/방어(정보 없으면 ???)·예고 말풍선·메시지, 아래쪽 가운데 주인공 체력·기력 바와 왼쪽 상태 효과, 행동 버튼 4개 (특수 행동은 B-3까지 비활성)
22. [B-2] 공격: 주사위 영역(굴리는 연출 0.5초 → 눈·조합·예상 피해 → 공격!) / 방어: 2초 동안 화면 어디든 클릭·터치할 때마다 +1.5%p (괴이별 상한) / 도망: 확률·실패 시 2배 안내 + 도망치기·취소, 보스·스토리는 불가 안내
23. [B-2] 결과: 승리(스토리 전투면 첫 클리어 플래그) → 구역 맵 / 도망 → 구역 맵 / 패배 → 골드 10% 손실, 체력 30% 부활, 복귀 장소(기본: 도심 안전 지역) 내부에서 시작. 체력·기력은 전투 사이에 유지
24. [B-1 보완] 예고 대응 성공(맞는 특수 행동으로 디버프를 막거나 반사 자세에 가만히 있기) → 괴이에게 빈틈(다음 공격 피해 +50%, 1턴)
25. [B-3] 특수 행동 창: 2×2 목록, X 닫기, ▶ 다음 페이지(끝에서 처음으로), 페이지 표시. 1쪽 스킬1·스킬2·가만히 있기·도발하기 / 2쪽 귀막기·호흡참기·입막기·음식먹기(개수). 쓸 수 없는 칸은 비활성
26. [B-3] 도발: 턴을 쓰지 않음 → 창이 닫히고 같은 턴에 다른 행동. 한 턴에 한 번 ("이번 턴 사용함")
27. [B-3] 스킬: 주사위를 굴린 뒤 공격 영역에 "다시 굴리기 (기력 2)"·"주사위 고정 (기력 3)" 버튼. 다시 굴리기는 공격당 1번, 주사위 고정은 고정할 주사위를 눌러 선택 → 다음 공격 첫 주사위로 고정(노란 글자). 기력 부족 시 비활성. 특수 행동 창의 스킬 칸은 표시용(“공격 중 주사위를 굴린 뒤 사용”)

## 결정 사항

- 개발 방식 (11/26): 바이브 코딩. Claude Code = 코드·씬·Inspector·테스트 (Unity MCP), 사용자 = 최종 검토·커밋
- 장소 내부 나가기 버튼은 좌상단, 대화 중에도 누를 수 있음 (다시 들어오면 대화창 초기화됨) (A-1)
- 데이터·상태 분리 (A-2): 데이터(PlaceData·NpcData 에셋)는 읽기 전용, 진행 상태는 GameStateManager 한곳. 상태 키는 이름이 아닌 ID (이름은 교체 가능, ID는 출시 후 변경 금지)
- 상태 키 (A-3): StateKeys에서만 생성. 형식 "종류:장소ID:상호작용ID[:추가정보]", ID에 ':' 금지. 대화 1개마다 선택 여부 + 고른 선택지 번호 기록 (장소당 대화 개수 제한 없음). 기존 "clerkChoice:" 키는 폐기 (세이브 파일 없어서 호환 불필요)
- 장소 내부 구성 (A-3): 고정 버튼 3개 대신 상호작용 목록. 종류는 Investigate/Talk, D단계에서 Shop 등 추가. 나가기는 고정 버튼 유지
- 이름 규칙 (A-3): 지역 = Region, 구역 = Area, 장소 = Place. 장소 데이터 = PlaceData, 지도 위 마커 = MapMarker (A-4에서 LocationMarker 대체)

- 커리큘럼 B 완료 기준 "서식지에서 랜덤 괴이와 조우해 처음부터 끝까지 전투하고 복귀" — 통합 테스트에서 산·강·도심 일반 전투를 버튼으로 끝까지 진행해 충족

  - 통합 테스트 전투 기록: 일반 5전 모두 승리(13~23틱), 보스 승리(만화 3번 = 입장 1 + 페이즈 2, 1페이즈 도발 3번, 예고 대응 4번), 패배 → 복귀(체력 30%, 골드 100→90), 도망 성공

### 남은 문제 (B단계 범위 안에서 미뤄 둔 것)

1. OST·효과음: AudioClip 칸만 있음, 재생 없음 → E단계 "사운드 재생 구조"
2. 괴이 수: 일반 5종(도심 2·산 2·강 1) + 보스 1. 첫 출시 목표 10종 이하 → D단계 콘텐츠
3. 실제 마우스·터치 손맛(방어 연타 2초, 주사위 연출 속도, 만화 넘김)은 사용자 검토 필요. 테스트는 버튼 클릭 흉내(레이캐스트)로 진행
4. 프로필·설정 버튼은 자리만 (C단계 홈·스탯 창)
5. 시작 장비로 보스 승률 40% (1페이즈 도발 시 57%) — 적정 장비(공격 +5·방어 +10) 기준으로 맞춤. C단계 장비 수치를 이 기준에 맞춰야 함
6. 기력: 스킬을 쓰면 약 1.9번째 전투에서 바닥남 → C단계 기력 회복 수단과 함께 조정
7. (테스트 도구 문제, 게임 아님) 통합 테스트 러너가 도는 중에 MCP 화면 캡처를 하면 Console에 "PlayerLoop called recursively" 오류 5건 (1회차, 캡처 3번). 캡처 없이 다시 돌린 2회차는 111/111·Console 0, 러너가 멈춘 뒤 캡처 1번도 0 → 러너 실행 중에는 캡처하지 않기
8. 폰트 SDF 용량·경고 → E단계 (기존)

### C단계 시작 전 필요한 결정

1. 보상: 일반 전투 골드·아이템 드롭 범위, 스토리·보스 첫 클리어 보상과 재도전 20%를 어디까지 적용할지 (일반 전투에도?)
2. 병원: 체력·기력 치료 비용(따로), 병원을 들르면 복귀 지점이 바뀌는 방식, 게임 시작 시 병원 방문을 어떻게 강제할지(첫 장소 고정?)
3. 상점: 일반/특수 상점 구분(특수만 판매 탭), 판매 목록·가격, 소비 아이템 종류(음식·기력 회복 등)
4. 장비: 주사위 무기 3종(일반·고급·희귀)의 공격·효과와 스킬 배정(일반 1개·고급/희귀 2개?), 방어구 종류·방어 수치 — 보스 적정 장비(+5/+10) 기준과 맞출지
5. 성장: 주사위 면 수·개수 증가를 무엇으로 얻는지(골드 강화? 무기 등급?), 비용 곡선. 면이 늘면 조합 확률이 줄어드는 선택 요소를 어떻게 보여줄지
6. 홈·스탯 창: 전투 화면의 프로필 버튼에서 열지, 지도 화면 상단 UI(골드 표시 포함)에서 열지
7. 기력 경제: 스킬 사용 빈도 목표(전투당 몇 번?)와 기력 회복 아이템 가격
