# 《요원》 기획 요약 및 개발 로드맵

> 2026-11-26 개정: 학습 중심 1년 커리큘럼 → 바이브 코딩 중심 단기 출시 로드맵(A~F).

## 1. 개요

- 프로젝트 시작일: 2026-10-23
- 개발 완료 목표: 2027-01-07 (스토리·그래픽 제외 게임 기능 전체)
- 출시: 사용자가 스토리·그래픽을 채운 뒤 itch.io(웹) 공개. 출시일은 콘텐츠 준비 상황에 따라 결정
- 스토어(Android 등): 웹 출시 후 반응을 보고 결정 (Android는 약 3~4주 추가 필요)
- 작업 시간: 주 약 20시간
- Git: Fork 사용, GitHub https://github.com/dlsrb/first-agent

## 2. 게임 기획

- 장르: 가까운 미래의 가상 한국 배경 현대 판타지, 괴이 탐사, 스토리 중심 RPG
- 분위기: 밝지만 어딘가 이상하고 무언가 숨겨진 세계. 일상 장소에서 비일상 사건을 발견하는 경험
- 핵심 플레이: 지도 탐색 → 장소 진입 → 사건·NPC·괴이 → 턴제 전투 → 성장
- 장소 유형: 일반(탐색·인물), 안전(휴식·정비·상점, 예: 편의점·병원), 위험(괴이 조우·전투), 특수(조건부 이벤트)
- 전투: 텍스트·선택지 중심 턴제. `docs/전투시스템.md` 참고
- 온라인(랭킹·길드): 출시 후 검토

### 맵 구조 (맵 구상도 기준)

- 전체 맵(가상 한국, 특별시·광역시·도) → 지역 맵(~구, ~마을, ~산, ~강) → 구역 맵(편의점, 학교, 음식점, 병원, 뒷골목 등) → 장소 내부(예: 안전 구역 — 물건사기/대화하기/나가기) → 상점 구매창(상품 이미지·이름·효과·소지 개수·구매 버튼, 특수 상점만 판매 탭)
- 공통 상단 UI(가상 시간, 골드, 프로필, 설정)는 첫 출시에서 골드만 필수
- 현재 Unity의 장소 4개 화면 = "구역 맵"에 해당
- 지도는 실제 지도 캡처·트레이싱 금지, 가상 지도 사용. 실제 상호명 지양

## 3. 첫 출시 분량

- 지역 1개 (구역 1~2개 + 산 + 강)
- 스토리 장소는 고정, 산·강·위험 구역은 서식지별 괴이 랜덤 등장
- 괴이 10종 이하 (산 서식 / 강 서식 등), 보스 1종
- 스토리 1챕터 분량의 이벤트 구조 (텍스트는 비워 둠)

### 첫 출시 제외

카드 무기, 실시간 전투, 무기별 터치 조작, 유료 재화·유료 상점, 온라인 기능, 가상 시간, 외곽·바다·?? 거점

## 4. 콘텐츠 원칙

- 스토리 텍스트, 대사, 캐릭터·괴이·배경 이미지는 비워 두고 사용자가 나중에 채운다
- 개발 중에는 임시 텍스트와 회색 도형만 사용
- 텍스트·이미지는 ScriptableObject 칸으로 만들어 코드 수정 없이 교체
- 수치와 이벤트 흐름은 임시로 잡고 이후 조정

## 5. 로드맵 (주 20시간 기준)

| 단계 | 기간 | 내용 |
|---|---|---|
| A. 기반 정리 | 11/27~12/3 | 가로 화면 전환, 데이터와 상태 분리, 지역→구역→장소 구조, 장소·NPC 데이터 ScriptableObject 전환 |
| B. 전투 | 12/4~12/13 | 턴제, 기본 행동 4개, 주사위 공격, 괴이 데이터, 서식지별 랜덤 조우, 승리·패배·복귀 |
| C. 성장·경제 | 12/14~12/20 | 골드, 상점 구매창, 아이템, 주사위 강화·무기 강화, 전투 보상 |
| D. 콘텐츠 틀 | 12/21~12/27 | 스토리 이벤트 시스템(조건·분기·진행 기억), 괴이 10종·보스 1종 데이터(임시 이미지), 장소 유형별 내부 구성 |
| E. 마무리 | 12/28~12/31 | 세이브/로드, 사운드 재생 구조, 한글 폰트 용량 줄이기 |
| F. 빌드 | 1/1~1/7 | WebGL 빌드, 웹 환경 테스트, 버그 수정 |

- 일정이 밀리면 괴이 수, 보스 기믹, 이벤트 수를 먼저 줄인다

## 6. 단계 완료 기준

- A: 가로 화면에서 지도→구역→장소 이동이 되고, 새 장소를 데이터 파일 추가만으로 만들 수 있다
- B: 서식지에서 랜덤 괴이와 조우해 처음부터 끝까지 전투하고 복귀할 수 있다
- C: 전투로 골드를 얻고, 상점에서 아이템을 사서 쓰고, 강화가 전투에 반영된다
- D: 데이터만 채우면 스토리 이벤트, 괴이, 보스가 게임에 나타난다
- E: 게임을 껐다 켜도 진행이 유지된다
- F: 웹 브라우저에서 처음부터 끝까지 진행을 막는 오류가 없다
